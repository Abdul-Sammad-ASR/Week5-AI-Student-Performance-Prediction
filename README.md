# 🤖 AI Student Performance Prediction System

An AI-based intelligent system developed as part of **Week 5 of the DevSphere AI Internship Program**.

## 📌 Project Overview

This project uses **Machine Learning** to predict a student's final marks based on:

* Study Hours
* Attendance
* Previous Marks
* Sleep Hours

The system takes student information as input and predicts their expected final marks and grade.

## 🛠️ Technologies Used

* Python
* NumPy
* Pandas
* Scikit-learn
* Matplotlib
* Linear Regression

## ⚙️ Features

* Dataset loading and preprocessing
* Missing-value handling
* Duplicate removal
* Train-test data splitting
* Feature scaling using StandardScaler
* Linear Regression model training
* Model evaluation
* Student marks prediction
* Grade prediction
* Data visualization
* User input handling

## 📊 Model Evaluation

The model is evaluated using:

* Mean Absolute Error (MAE)
* Mean Squared Error (MSE)
* Root Mean Squared Error (RMSE)
* R² Score
